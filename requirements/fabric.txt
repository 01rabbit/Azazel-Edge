# Azazel-Fabric shared contracts — OPTIONAL integration extra.
#
# Installing this file activates Edge's Fabric projections and the AZ-06
# deception shadow/replay boundary. Without it, Fabric integrations remain
# optional and baseline Edge behavior is unchanged.
#
# Pin policy: an exact tagged release, never a branch and never a development
# commit, for field deployment.
#
# v0.10.0 is the stable release, at the annotated tag's commit
# 397fcce7a87ca7ab1a5e84bc196c44d70c404907 (digest
# sha256:d789f27464114bf29bbdc64fcc515cdbdfc02903a0b42af4de3dc707446e302f).
# Its src/ differs from v0.10.0rc1 only in version.py, so the contract surface
# is rc1's (the rc1 notes below still describe it). The release-owner
# signature (release/v0.10.0.digest.json.sig) is inside the tag's tree. Verify
# with the tag's `tools/rc_digest.py --check` and
# `tools/rc_signature.py --check`.
#
# History: v0.10.0rc1 was the candidate pin, at tag commit
# 36db04412679e2694d697595cbf913d0bfc72019 (digest
# sha256:114402979360855ccaeb92fcc1851db1b03572a289c43e3591633f263b7559eb;
# signature inside the tag's tree). It was pinned because it is the first tag
# carrying the producer captures in `azazel_fabric.testing`
# (Azazel-Fabric#23, #85) -- records Azazel-Edge and Azazel-Deception actually
# emitted -- which Edge's consumer tests read (Deception's captures through
# Edge's consumers). Its leaving condition -- move to v0.10.0 when that
# stable release is cut -- is met by this pin.
#
# rc1 (and so v0.10.0) is ADDITIVE over v0.9.0: its src/ adds the experimental
# `knowledge_context` family and the `testing` producer captures and changes
# version.py; no released symbol changed. The four stable families
# (deception, effect, engagement, outcome) are unchanged, so the contract
# surface Edge uses is v0.9.0's. Five families are experimental (cti, mio,
# external_security, provisioning, knowledge_context).
#
# History: v0.9.0 was the stable pin, at tag commit
# ee2ab8cf5173b5967481d2452dfd5fd8cf76ade6 (digest
# sha256:5107054682802f1e615615d0de51471859014d31a8808b61d8cbf6c16b27dbf4).
# Its src/ differs from v0.9.0rc6 only in version.py, so its contract surface
# is rc6's (the rc6 notes below still describe it); its signature is inside
# the tag's tree. Fabric's CHANGELOG [0.9.0] separates stable from
# experimental surfaces and does not claim an aggregate attestation or
# golden-fixture interoperability.
#
# v0.9.0rc6 was a release candidate at tag commit
# 023381371b56b3883a89a28a69625ddb87742f2e (digest
# sha256:f1b76901bee8938b45b5a600d967286b7a397933acdbecb30328c6adad1ab1e6).
# Its release-owner signature was added AFTER the tag, on Azazel-Fabric main
# (88c47d5, release/v0.9.0rc6.digest.json.sig); that tag does not contain it.
#
# rc6 is NOT additive over rc5 (the pin moves rc4 -> rc6, so rc5 is skipped):
#   - Azazel-Fabric#65: a typed reference, a provisioning digest or a MAC that
#     ends in a newline is refused (it validated under rc5).
#   - Azazel-Fabric#23: a payload nested more than 32 levels deep, passed to a
#     deception, engagement or effect directive guard, is refused with a
#     ValueError even when it carries no directive.
#   - Azazel-Fabric#72: a decision_ref, activation_decision_ref, trace_id or
#     EffectObservation.execution_ref typed `observation_objective:`,
#     `hypothesis:` or `frame:` is refused where rc5 read it as untyped. The new
#     optional envelope fields (observation_objective_ref, hypothesis_refs,
#     frame_ref, limitations) are additive.
# Edge produces none of these. rc5 itself was additive over rc4 (optional
# PresentedTerrainRef bindings for decision-less effects).
#
# rc4 was the first non-additive step: an `EffectObservation` may claim only
# `observed_fact` or `active_materialized` (Azazel-Fabric#52). Four authority
# classes that v0.9.0rc3 accepted stay refused. Edge's
# `effect_observation_reader` already refused the same four locally. A
# candidate move cannot be treated as free; check each one.
#
# This pin skips v0.9.0rc3, which widened the typed-reference grammar so a
# reference body may carry further colons. Edge mints `edge:nft:1` and was
# refused by every slot requiring a typed ref under the rc2 grammar, so rc3 is
# not optional for Edge either; it arrives here as part of the same move.
#
# Earlier: v0.9.0rc2 was the first tag to contain `schema.defensive_state` —
# the canonical Defensive State vocabulary (Azazel-Fabric#14, Azazel#62). Edge keeps its own
# `DEFENSIVE_STATES`, because the arbiter must run with no Fabric installed at
# all; what this pin buys is the *drift guard*
# (`tests/test_defensive_state_vocabulary.py`), which compares the two and
# fails if they ever disagree. That test skips when Fabric does not carry the
# vocabulary, so before this pin it was guarding nothing in CI.
#
# Earlier: v0.9.0rc1 was the first tag to contain `outcome_contracts`, the
