# Explicit abstract witness wiring for the manual lab

The manual positive and separate synthetic-refusal commissioners pass their
held owned EDGE FD to a bounded Root metadata child before preparation. It joins
EDGE and samples a fresh unbound AF_UNIX socket cookie plus actual kernel boot ID.
Only that descriptor enters `prepare(..., witness_network_namespace=...)`, explicitly
provisioning trust v4 and its scope-derived abstract address. Device/inode remains
separate Root ownership evidence; cookie is not an inode or cross-kernel identity. The
pathname transport and existing product/legacy defaults remain unchanged; no
pathname failure selects a fallback. Only this manual lab renders the witness
with `Type=exec`, `NotifyAccess=none`, no `--systemd-notify`, and the literal owned
EDGE namespace path. The original witness template and product defaults stay
unchanged. No AppArmor rule,
capability, private-proc gate or runtime bound is broadened.

Before either initializer/live GO and after its API result, Root independently
resamples the still-held EDGE cookie/boot and checks the fixed live witness
PID/start time, enforcing label, separate owned EDGE device/inode,
typed effective command/properties and protected unit-file identity/hash. These
stable facts, explicit transport metadata and the public trust digest enter the
shared binding. Mutable witness counters do not. Root also requires one exact
abstract STREAM listener in `/proc/<PID>/net/unix` and one matching socket FD held
by the same witness PID, with stable inode/FD across later bindings. Only initial
pre-Popen initialization may passively poll a well-formed absent listener for up
to two seconds; unknown, duplicate or changed identity fails immediately, and
later phases do not poll. Each bounded raw table/FD sample is separately retained.
A listener establishes metadata readiness, never authentication: actual signed
initializer preflight and the original sealed-Switch proof remain required.
Raw Root observations are retained;
they are not cryptographic observer-label proof or endpoint probes.

Sealed Switch still calls the original `Systemd.witness` proof. A temporary lab
adapter performs that call inside an owned Root fork joined to EDGE, preserving
the original UID61002 subprocess, credentials, five-second proof and signatures.
The parent never joins EDGE. A child READY/ACK fence proves PID/start/session/group
ownership before descendants may spawn. Receipt/wait is bounded, and group
emptiness is checked while the unreaped leader reserves its PID. Forced or unknown
cleanup poisons namespace state; an unknown group retains the leader reservation.
No group signal follows reaping. Only the owned Root child receives the namespace
FD; the original observer subprocess keeps its original close-fds behavior.
Both commissioners restore their temporary Python prepare/witness adapters.

The original three pre-API FIFOs, two-second GO and 40s/5s role bounds remain.
The Root parent never enters EDGE; no key, Source RPC or endpoint connection is
used by metadata sampling. Failed or changed samples block preparation/GO/success
and poison namespace cleanup. Actual endpoints independently check their same
fresh unbound socket before bind/connect or witness-store/key access. The cookie
binds a kernel-lifetime namespace plus current boot, not rollback resistance.
No namespace is selected from untrusted JSON. Tests use synthetic Root/namespace
facts and fake setns, with real private fork/pipe/group/reap checks; they establish
no actual role, transport, sealed Switch or VM acceptance by themselves. One
scoped positive VM result is recorded in [the commissioning guide](SIGNED_TELEMETRY_COMMISSION.md#reviewed-positive-runtime-evidence-v8-2026-11-12);
the separate signature-refusal result is recorded there too. No four-run manifest,
