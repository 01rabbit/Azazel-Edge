`EDGE_SIGNED_NETWORK_UNIT_REFUSAL=1`, Root and unchanged current commissioning
prerequisites. Root must authenticate the full source archive externally; the
actual helper bytes are included in the material source map and entered receipt.
Revision text and recorded hashes do not authenticate themselves.

The current manual owner provisions its normal fresh namespaces, marker, empty
public scope and witness. Only at its actual initializer callback does this
helper record entry, sample the owned transport context and running witness,
and require the existing fixed passive witness barrier (canonical abstract
listener, same PID/socket-FD identity, owned EDGE and measured cookie/boot). Its

original witness anchors. It exclusively creates the fixed initializer's `.service.d` directory
and `90-fixed-refusal-marker.conf` under `/etc/systemd/system`. The fixed hook

reload, permission/profile/capability change, arbitrary path or command selector
exists. The Root-owned foreign file and directory are deliberately retained.

The unchanged initializer must raise the exact inherited-material refusal before
its intent, Popen, PREAPI or GO. The helper retains the original successful

foreign metadata/hash plus marker absence. Marker absence alone proves nothing:
AA/DAC could also prevent the marker. If initialization unexpectedly returns,
the decorator raises immediately so the ordinary core/native/live path cannot
continue. Generic errors and partial evidence never count as the expected refusal.

is made. All transition, experiment, measurement and admission flags remain false.
