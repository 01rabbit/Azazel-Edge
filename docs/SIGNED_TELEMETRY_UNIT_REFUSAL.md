# Fixed inherited initializer-material negative

`refuse_inherited_initializer_material(output, **five_external_pins)` is an
explicit manual test helper. It requires a fresh protected offline VM,
`EDGE_SIGNED_NETWORK_TELEMETRY=1`, the additional
`EDGE_SIGNED_NETWORK_UNIT_REFUSAL=1`, Root and unchanged current commissioning
prerequisites. Root must authenticate the full source archive externally; the
actual helper bytes are included in the material source map and entered receipt.
Revision text and recorded hashes do not authenticate themselves.

The current manual owner provisions its normal fresh namespaces, marker, empty
public scope and witness. Only at its actual initializer callback does this
helper record entry, sample the owned transport context and running witness,
and require the existing fixed passive witness barrier (canonical abstract
listener, same PID/socket-FD identity, owned EDGE and measured cookie/boot). Its
private evidence child is outside `initialize/`, with no endpoint connection or
Source RPC. Only then snapshot the empty Source, empty observer directory and
original witness anchors. It exclusively creates the fixed initializer's `.service.d` directory
and `90-fixed-refusal-marker.conf` under `/etc/systemd/system`. The fixed hook
would invoke `/usr/bin/touch /run/edge400-inherited-initialize-marker`. No daemon
reload, permission/profile/capability change, arbitrary path or command selector
exists. The Root-owned foreign file and directory are deliberately retained.

The unchanged initializer must raise the exact inherited-material refusal before
its intent, Popen, PREAPI or GO. The helper retains the original successful
`systemd-analyze unit-paths` argv/stdout/stderr/result, requires no other initializer
artifacts or live artifacts, and verifies unchanged public bytes/identities and
foreign metadata/hash plus marker absence. Marker absence alone proves nothing:
AA/DAC could also prevent the marker. If initialization unexpectedly returns,
the decorator raises immediately so the ordinary core/native/live path cannot
continue. Generic errors and partial evidence never count as the expected refusal.

The existing owner always attempts its cleanup, witness last, before namespace
closure. Independent receipts, all seven original/canonical cgroups, absence of
native actors/namespaces, unchanged parent network and boot are required before
publishing `inherited_initializer_material_refusal_complete`. Failures remain
sticky; evidence and the injected foreign material are never deleted or repaired.
The fixture is an intentional host-file delta, so no whole-host unchanged claim
is made. All transition, experiment, measurement and admission flags remain false.

Focused tests use synthetic actor/Root ownership facts and actual private files
and the unchanged material guard. A separate Root-only physical-file regression
checks exclusive creation, exact permissions under umask 077, identity continuity
and no retry. The reviewed integration passed 179 focused checks in offline Linux
as explicit UID0 with all capabilities dropped, including that physical-file case.
This proves neither arbitrary systemd-hook safety nor admission or efficacy; it
starts no workload, native Source producer, Switch or four-assignment experiment.
